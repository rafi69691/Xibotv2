# ⚡ Quotex AI Pro Signal Bot (Telegram Auto Signal & Chart Generator)

একটি স্বয়ংক্রিয় Quotex ট্রেডিং সিগন্যাল বট যা আপনার Telegram চ্যানেল বা গ্রুপে **লাইভ মার্কেট ক্যান্ডেলস্টিক চার্ট**, **সিগন্যাল (CALL/PUT)**, এবং নির্দিষ্ট এক্সপায়ারির পর **অটোমেটিক WIN/LOSS রেজাল্ট** পাঠাতে সক্ষম।

---

## 📁 ফাইল স্ট্রাকচার (File Structure)

- `telegram_bot.py` : প্রধান টেলিগ্রাম বট ফাইল (কমান্ড হ্যান্ডলার, অটো-ব্রডকাস্টার, রেজাল্ট ট্র্যাকার)।
- `chart_generator.py` : ডার্ক থিমযুক্ত হাই-টেক ক্যান্ডেলস্টিক চার্ট জেনারেটর (EMA 9, EMA 21, ভলিউম বার, ওয়াটারমার্ক ও সিগন্যাল ব্যাজ সহ)।
- `strategy.py` : টেকনিক্যাল অ্যানালাইসিস ইঞ্জিন (EMA ক্রসওভার, RSI এক্সট্রিম জোন, বলিঙ্গার ব্যান্ড ও পিন-বার রিজেকশন)।
- `quotex_feed.py` : Quotex OTC এবং ফরেক্স পেয়ারের জন্য রিয়েল-টাইম ক্যান্ডেলস্টিক ডাটা বাফার ও ফিড।
- `config.py` : বট টোকেন, চ্যানেল আইডি, পেয়ার লিস্ট এবং সেটিংস।
- `requirements.txt` : প্রয়োজনীয় পাইথন লাইব্রেরি।

---

## 🚀 সেটআপ ও ইনস্টলেশন নির্দেশিকা (Step-by-Step Setup)

### ১. Telegram Bot টোকেন তৈরি করুন:
1. টেলিগ্রামে গিয়ে `@BotFather` সার্চ করুন।
2. `/newbot` লিখে সেন্ড করুন।
3. আপনার বটের নাম এবং ইউজারনেম দিন (যেমন: `my_quotex_signal_bot`)।
4. একটি **HTTP API Token** পাবেন, সেটি কপি করে রাখুন।

### ২. কনফিগারেশন (`config.py`):
`config.py` ফাইলে আপনার টোকেন ও চ্যানেল আইডি বসান:
```python
BOT_TOKEN = "YOUR_TELEGRAM_BOT_TOKEN_HERE"
CHANNEL_ID = "@your_channel_username" # অথবা আপনার গ্রুপের আইডি
```

### ৩. ডিপেন্ডেন্সি ইনস্টল করুন:
```bash
pip install -r requirements.txt
```

### ৪. বট চালু করুন:
```bash
python telegram_bot.py
```

## 🎮 টেলিগ্রাম বটের কমান্ডসমূহ:

- `/start` : বটের ড্যাশবোর্ড ও ওয়েলকাম মেসেজ।
- `/signal` : তাৎক্ষণিকভাবে মার্কেট অ্যানালাইসিস করে একটি সিগন্যাল ও চার্ট পাঠাবে।
- `/auto` : প্রতি ৩ মিনিটে স্বয়ংক্রিয়ভাবে সিগন্যাল পাঠানো অন/অফ করবে।
- `/stats` : সারাদিনের মোট WIN/LOSS ও পারসেন্টেজ রেজাল্ট দেখাবে।
- ইনলাইন বাটন: **📊 Partial Result** এবং **📈 Daily Full** বাটনে চাপ দিয়ে যেকোনো সময় বর্তমান স্কোরবোর্ড পাওয়া যাবে।
